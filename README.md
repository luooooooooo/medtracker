# 打卡了吗？

一个圆润治愈的安卓通用打卡应用：无论是饭后喝药、上班工作还是完成日常事项，都可以自定义成你的打卡内容。按每日 1~6 次展示待打卡卡片，点击卡片完成打卡并亮起完成标记，全部完成时播放庆祝动画，自动记录每日完成情况、统计连续完成天数，并支持日历查看每日打卡情况。

## 功能

- 通用打卡：顶部大标题、每张卡片标题与时间副标题、底部提示语全部支持自定义（喝药、上班、学习、习惯养成皆可）
- 每日 1~6 次自定义：时段卡片自动增减
- 桌面小部件：主屏幕直接点击打卡，随主题/次数/零点自动同步，尺寸随次数自适应（1~3 次单行、4~6 次双行）
- 完成庆祝：全部打卡完成播放彩带动画
- 日历统计：按月查看每日打卡情况，点击日期查看当天详情
- 连续天数：自动统计连续完成天数
- 自定义头图：相册选图 + 比例裁剪（仅点击图片本身可更换）
- 10 套莫兰迪主题：薄荷 / 雾蓝 / 墨黑 / 豆沙粉 / 香芋紫 / 鼠尾草 / 燕麦 / 陶土 / 鸢尾蓝 / 梅子

## 使用说明

1. 安装 APK 后打开，进入当日打卡页
2. 点击卡片即可完成对应时段的打卡
3. 点击右上角调色板按钮：切换主题、设置每日打卡次数、更换头图、自定义文字
4. 点击右上角日历按钮查看历史打卡记录
5. 每天 0 点自动进入新的一天，打卡状态自动清零
6. 长按桌面空白处添加「打卡了吗？」小部件，可直接在桌面打卡
7. 单击头图图片本身可更换照片，点击其他区域不会触发

## 技术栈

- Kotlin-free：纯 Java（AndroidX + Material Components 3）
- minSdk 26 / targetSdk 34
- 数据本地存储：SharedPreferences
- 无任何网络权限，数据仅保存在本机

## 构建

```bash
export JAVA_HOME=<JDK17路径>
export ANDROID_HOME=<Android SDK路径>
gradle assembleRelease
```

产物：`app/build/outputs/apk/release/app-release.apk`

> 说明：签名密钥 `release.keystore` 与 `local.properties` 属本地配置，已通过 `.gitignore` 排除，不随仓库分发。如需重新签名发布，请自行准备签名文件并在 `app/build.gradle` 中配置。
