# 饭后喝药打卡

一个圆润治愈的安卓喝药打卡应用：按早、中、晚（可自定义每日 1~6 次）展示待打卡卡片，点击卡片完成打卡并亮起完成标记，全部完成时播放庆祝动画，自动记录每日完成情况、统计连续完成天数，并支持日历查看每日打卡情况。

## 功能

- 每日按时段打卡：早/中/晚饭后等 6 个预设时段，可自定义每天 1~6 次
- 桌面小部件：主屏幕直接点击打卡，随主题/次数/零点自动同步
- 完成庆祝：全部打卡完成播放彩带动画
- 日历统计：按月查看每日打卡情况，点击日期查看当天详情
- 连续天数：自动统计连续完成天数
- 自定义头图：相册选图 + 比例裁剪
- 10 套莫兰迪主题：薄荷 / 雾蓝 / 墨黑 / 豆沙粉 / 香芋紫 / 鼠尾草 / 燕麦 / 陶土 / 鸢尾蓝 / 梅子

## 使用说明

1. 安装 APK 后打开，进入当日打卡页
2. 点击卡片即可完成对应时段的打卡
3. 点击右上角调色板按钮可切换主题、设置每日喝药次数、更换头图
4. 点击右上角日历按钮查看历史打卡记录
5. 每天 0 点自动进入新的一天，打卡状态自动清零
6. 长按桌面空白处添加「饭后喝药打卡」小部件，可直接在桌面打卡

## 技术栈

- Kotlin-free：纯 Java（AndroidX + Material Components 3）
- minSdk 26 / targetSdk 34
- 数据本地存储：SharedPreferences
- 无任何网络权限，数据仅保存在本机

## 构建

```bash
export JAVA_HOME=<JDK17路径>
export ANDROID_HOME=<Android SDK路径>
gradle assembleRelease
```

产物：`app/build/outputs/apk/release/app-release.apk`

> 说明：签名密钥 `release.keystore` 与 `local.properties` 属本地配置，已通过 `.gitignore` 排除，不随仓库分发。如需重新签名发布，请自行准备签名文件并在 `app/build.gradle` 中配置。
